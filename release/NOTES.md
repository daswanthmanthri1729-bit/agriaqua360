## AgriAqua 360 — Level 1 (v1.0.0)

AI-powered farming app for **agriculture, aquaculture and livestock**, in **English, తెలుగు and हिन्दी**.

### Downloads
| File | For |
|---|---|
| `AgriAqua360-v1.0.0.apk` | Android phones (Android 8+) |
| `AgriAqua360-Windows-x64.zip` | Windows 10/11 (64-bit) — unzip and run **AgriAqua 360.exe** |

### Install
- **Android:** open the APK on the phone → allow "Install unknown apps". If Play Protect warns, tap **More details → Install anyway** (the app is not on the Play Store yet).
- **Windows:** unzip → run `AgriAqua 360.exe`. If SmartScreen warns, click **More info → Run anyway** (the app is not code-signed yet).

### What's inside
- 40 screens: onboarding, farms & crops, crop calendar, weather, crop disease scanner, ponds & water quality, fish health scanner, livestock health & vaccinations, AI assistant (text, voice, photos), notifications, saved records, reports, profile, help.
- AI answers stream word-by-word; voice questions in Telugu/Hindi/English; weather warnings and farm reminders as notifications; works with saved data when offline.
- AI photo results are preliminary guidance, not a lab test — consult an expert for serious problems.
